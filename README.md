# QIDI Tech Plus 4 Config Management

Комплексная система для управления конфигурациями, моделями и логами принтера QIDI Tech Plus 4.

## Быстрая настройка

Для полной подготовки рабочего окружения запустите **`setup.bat`** в корне проекта.

### Что делает `setup.bat`:

1.  **На стороне принтера (через SSH):**
    *   Подключает архивные репозитории Debian Buster (необходимо для старых систем).
    *   **Устанавливает Samba**: настраивает шару `QidiRoot` с полным доступом к корню `/`.
    *   **Устанавливает Unison**: серверную часть для быстрой синхронизации.
    *   Настраивает права доступа и разрешает переход по системным ссылкам (symlinks).
2.  **На стороне ПК (Windows):**
    *   **Устанавливает Unison**: клиентскую часть (через `winget`).
    *   **Монтирует диск `Z:`**: подключает корень принтера как сетевой диск для прямого доступа через Проводник или IDE.
    *   **Генерирует SSH-ключи**: настраивает беспарольный вход, чтобы синхронизация не запрашивала пароль каждый раз.
    *   **Создает профили Unison**: подготавливает 4 сценария синхронизации (`config`, `models`, `logs`, `media`).

## Синхронизация

Для запуска **автоматической** фоновой синхронизации используйте **`unison_start.bat`**.
Скрипт будет висеть в фоне и каждые 2 секунды проверять изменения в обе стороны (для конфигов и моделей) и стягивать новые логи/медиа.

### Режимы работы профилей:
*   **Конфиги (`etc`, `config`)**: Двусторонняя синхронизация ↔. Изменения в IDE улетают на принтер, правки на принтере прилетают в проект.
*   **Модели (`gcodes`)**: Двусторонняя синхронизация ↔. Удобно для загрузки нарезанных моделей.
*   **Логи и Медиа**: Односторонний вытяг (Printer → PC) ↓. Тяжелые файлы (видео, графики, таймлапсы) скачиваются для анализа, но игнорируются Git-ом.

## Структура проекта

*   **`setup.bat`** — Первичная настройка "под ключ".
*   **`unison_start.bat`** — Запуск авто-синхронизации (Live Sync).
*   **`Tools/`** — Скрипты автоматизации:
    *   `printer-sync.psm1` — Основной модуль логики.
    *   `setup_printer.ps1` — Скрипт подготовки Linux-части принтера.
*   **`home∕mks∕...`** — Локальные копии файлов принтера (с использованием спецсимвола `∕` для совместимости путей).

## Требования
*   Windows 10/11 с PowerShell 5.1+.
*   Доступ к принтеру по сети (по умолчанию IP `192.168.100.194`).
*   Пароль пользователя `mks` (по умолчанию `makerbase`).

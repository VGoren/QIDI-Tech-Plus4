# QIDI Tech Plus 4 Config Management (Rclone Edition)

Комплексная система для управления конфигурациями, моделями и логами принтера QIDI Tech Plus 4 через сетевой диск и современную систему синхронизации Rclone.

## Быстрая настройка

Для полной подготовки рабочего окружения запустите **`initialize.bat`** (или соответствующий сценарий) в корне проекта.

### Что делает инициализация:

1.  **На стороне принтера (через SSH):**
    *   Подключает архивные репозитории Debian Buster (необходимо для системных обновлений).
    *   **Устанавливает и настраивает Samba**: открывает сетевой доступ `QidiRoot` ко всей файловой системе `/` принтера.
    *   Разрешает переход по системным ссылкам (symlinks) для прямого доступа к папкам конфигов.
2.  **На стороне ПК (Windows):**
    *   **Устанавливает Rclone**: основной движок синхронизации (через `winget`).
    *   **Монтирует диск `Y:`**: подключает корень принтера как полноценный сетевой диск Windows.
    *   **Генерирует SSH-ключи**: настраивает автоматический вход без ввода пароля.
    *   **Создает структуру проекта**: формирует папки с имитацией путей Linux (через спецсимвол `∕`).

## Синхронизация

Для синхронизации файлов используйте **`sync_all.bat`**.
Скрипт использует алгоритмы Rclone для интеллектуального сравнения локальной папки и сетевого диска.

### Режимы работы:
*   **Конфиги (`etc`, `config`)**: Двусторонняя синхронизация ↔. Изменения в IDE (VS Code и др.) мгновенно попадают на принтер, а правки, сделанные через веб-интерфейс (Fluidd/Mainsail), возвращаются в локальный Git-проект.
*   **Модели (`gcodes`)**: Двусторонняя синхронизация ↔. Модели синхронизируются между ПК и принтером, позволяя удобно управлять очередью печати.
*   **Логи и Медиа**: Односторонний вытяг (Printer → PC) ↓. Тяжелые данные (логи Klipper, видеозаписи, таймлапсы) скачиваются для архивации, но автоматически игнорируются Git-ом.

## Структура проекта

*   **`initialize.bat`** — Первичная настройка инфраструктуры и прав доступа.
*   **`sync_all.bat`** — Запуск мгновенной синхронизации (bisync / pull).
*   **`Tools/`** — Скрипты автоматизации:
    *   `initialize_printer.ps1` — Настройка принтера, диска Y и зависимостей.
    *   `sync_now.ps1` — Основная логика работы Rclone (очистка блокировок, сравнение папок).
*   **`home∕mks∕...`** — Локальные копии файлов. В названиях папок используется Unicode-слэш (`∕`) для полной имитации абсолютных путей Linux в файловой системе Windows.

## Требования
*   Windows 10/11 с PowerShell 5.1+.
*   Rclone (устанавливается автоматически).
*   Доступ к принтеру по сети (по умолчанию IP `192.168.100.194`).
*   Пароль пользователя `mks` (по умолчанию `makerbase`).

## Преимущества перед Unison
*   **Отсутствие зависимостей**: Принтеру не требуется специализированная "серверная часть" — работа идет через стандартную Samba.
*   **Стабильность**: Rclone более устойчив к обрывам связи и не чувствителен к несовпадению версий OCaml или дистрибутивов Linux.
*   **Прозрачность**: Все данные всегда доступны на сетевом диске `Y:`.
